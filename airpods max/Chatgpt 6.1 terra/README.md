# AirPods Max interactive study

A static Three.js product showcase. This folder contains the website source and bundled Three.js modules.

Run locally from this folder with `python3 -m http.server 8000`, then open http://localhost:8000/ in a browser. A WebGL 2 capable browser is required for the interactive model; a still image is shown otherwise.

This is an early conceptual reconstruction, not a hardware-accurate model. The 3D rendering and frame rate were not verified in the original preview environment because WebGL was unavailable.
